# Getting support

| I need… | Where to go |
|---|---|
| To report a bug or data issue in a project | Open an issue in that repository using the templates |
| Help using a Neudata package, app or workflow | Check the repository README and documentation, then open a 📘 Documentation or 📊 Request issue |
| Consulting, training or partnership enquiries | [www.neu-data.com](https://www.neu-data.com) · [contact@neu-data.com](mailto:contact@neu-data.com) |
| To report a security or data-protection concern | See [SECURITY.md](SECURITY.md) — **not** a public issue |
