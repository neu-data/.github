# Security & Data-Protection Policy

Neudata Consulting Ltd handles research, health and organisational data on behalf of clients. We take the security of our code and the confidentiality of that data seriously.

## Reporting a vulnerability or data exposure

**Please do not open a public issue.** Instead, report it privately:

- Use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on the affected repository (**Security → Report a vulnerability**), or
- Email **[contact@neu-data.com](mailto:contact@neu-data.com)** with the subject line `SECURITY`.

Please include:

- The affected repository, file or application
- A description of the issue and its potential impact
- Steps to reproduce, if applicable
- Whether any personal or confidential data may have been exposed

## What to expect

| Step | Target time |
|---|---|
| Acknowledgement of your report | within 3 working days |
| Initial assessment | within 7 working days |
| Fix or mitigation plan | communicated as soon as it is available |

We will keep you informed and credit you for the discovery if you wish.

## Exposed data or credentials

If you find credentials, tokens or personal data committed to any Neudata repository, report it immediately as above. Do not download, share or use the information.
